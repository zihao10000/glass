## 🚀 使用方法

### 方法 1：使用标记扩展（推荐）

在 XAML 中：

```xml
<!-- 添加命名空间 -->
<Window x:Class="GlassWarehouseSystem.InboundWindow"
        xmlns:local="clr-namespace:GlassWarehouseSystem.Services">
    
    <!-- 使用标记扩展 -->
    <MenuItem Header="{local:Lang Menu.System}"/>
    <Button Content="{local:Lang Btn.Start}"/>
    <TextBlock Text="{local:Lang Window.Inbound}"/>
</Window>
```

### 方法 2：代码后台设置

在 xaml.cs 中：

```csharp
public InboundWindow()
{
    InitializeComponent();
    ApplyLanguage();
}

private void ApplyLanguage()
{
    // 设置窗口标题
    this.Title = LanguageService.Get("Window.Inbound");
    
    // 设置按钮文本
    btnStart.Content = LanguageService.Get("Btn.Start");
    btnStop.Content = LanguageService.Get("Btn.Stop");
}
```

```xml
<Window x:Class="GlassWarehouseSystem.OutboundWindow"
        xmlns:local="clr-namespace:GlassWarehouseSystem.Services">
```

#### 步骤 3：替换为多语言绑定
```xml
<MenuItem Header="{local:Lang Outbound.System}"/>

<Button Content="{local:Lang Outbound.StartOutbound}"/>
<Button Content="{local:Lang Outbound.StopOutbound}"/>
```

#### 步骤 4：在代码后台应用语言
```csharp
public OutboundWindow()
{
    InitializeComponent();

}

private void ApplyLanguage()
{
    this.Title = LanguageService.Get("Window.Outbound");
}
```
